# 100 Days of Python — Days 1–45

A collection of exercises, notes, and projects completed while learning Python and related web fundamentals.

The source folder currently contains Days 1–45. Days 46–50 were not present when this archive was prepared.

API examples use environment variables for keys and mail credentials. Set each variable required by a project before running it (for example, API_KEY, NEWS_API_KEY, STOCK_API_KEY, or EMAIL_PASSWORD). OAuth credentials, access tokens, local environments, and personal datasets are intentionally excluded; supply your own local credentials and data when needed.
