## ✨ About this repository

This repository collects my Python coursework, practice exercises, and projects from the first part of the **100 Days of Code: The Complete Python Pro Bootcamp**. It follows my progress from core programming concepts to games, desktop tools, APIs, data handling, and introductory web development.

> **Progress note:** This repository includes the work available for Days 01–38 and 41–45. Day folders 39 and 40 are currently empty, and Days 46–50 were not included in the source material when this repository was prepared.

## 🧭 What I practiced

| 🧩 Fundamentals | 🎮 Projects & interfaces | 🌐 Practical tools |
|:---|:---|:---|
| Variables, input, conditionals, loops, functions | Games and interactive command-line apps | APIs and HTTP requests |
| Lists, dictionaries, and data structures | Turtle graphics and Tkinter GUIs | CSV files and data processing |
| Modules, exceptions, and basic debugging | Small HTML and CSS exercises | Web scraping with Beautiful Soup |

## 🌟 Project highlights

Some of the larger projects and topics represented in the day folders:

- 🎲 **Games:** Treasure Island, Rock Paper Scissors, Hangman, Blackjack, Number Guessing, Snake, Pong, and Turtle Crossing.
- ☕ **Interactive apps:** Coffee Machine, Quiz, Calculator, Password Generator, and Password Manager.
- 🐢 **Graphics:** Turtle art, turtle racing, and other drawing exercises.
- 📊 **Data and APIs:** U.S. States Quiz, NATO Phonetic Alphabet, Kanye quotes, weather alerts, stock news alerts, and workout tracking.
- 🖥️ **Desktop interfaces:** Miles-to-kilometers converter, Pomodoro timer, flash cards, and quiz apps.
- 🌐 **Web fundamentals:** HTML/CSS exercises and a web-scraping project.

The folders contain the individual lesson files and exercises, so use the day index below to explore the code and see each project in its original context.

## 🚀 Getting started

You will need Python 3 installed. Clone the repository, open a day folder, and run one of its Python files:

~~~bash
git clone https://github.com/fakharzamankhan/100-days-of-python.git
cd 100-days-of-python
python "Day01/010 Day 1.py"
~~~

Some exercises use third-party packages or external services. Check the individual file before running it and install the packages it imports. API and email examples may need your own credentials configured locally as environment variables.

## 🔐 Safe use

Credentials, access tokens, and private datasets are intentionally excluded. Keep API keys, passwords, and personal information out of commits. Add your own credentials through environment variables when a project requires them; never paste real secrets into source code.
